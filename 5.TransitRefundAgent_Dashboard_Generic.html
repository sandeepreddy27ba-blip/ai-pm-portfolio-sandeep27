🔒 Guardrail Architecture
NeMo Guardrails
🚫
Input Rail — Prompt Injection Defense
Blocks adversarial inputs attempting to override refund policies or escalate privileges. Pattern-matched + LLM classifier.
✅
Output Rail — Schema Validation
All payment trigger outputs validated against strict JSON schema before execution. Malformed outputs trigger human review queue.
💰
Financial Cap Guardrail
Automated refunds capped at $500 per patron. Batch limits set per event type. Exceeds → Supervisor approval required.
📊
Confidence Threshold Escalation
Agent confidence < 85% → auto-escalate to human-in-the-loop. Prevents LLM hallucination from triggering wrong refunds.
